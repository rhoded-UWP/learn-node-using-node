Lesson 4

Promises and async/await

How await waits without stopping the server, and why waiting for three things at the same time is faster than waiting for them one after another.

The idea

A promise is an object that stands for an answer that is not ready yet, such as a file being read or a timer counting down. Later the promise settles, and then the answer is ready.

Inside an async function, await pauses that function until the promise settles. The rest of the server keeps running. In Lesson 3 you saw that Node.js has one thread and an event loop. While a function is paused at await, the event loop is free to handle other requests.

That leaves a choice. When you need three slow things, you can await them one after another, so each one starts only when the one before it is done. Or you can start all three at the same time and wait for the whole group with Promise.all. The two demos below each wait 1000 ms three times, one way each.

The code

This is the code behind both demos, copied from this site's own source. First, demos.js imports a timer that returns a promise:

demos.js 
import { setTimeout as wait } from 'node:timers/promises';

The core module node:timers/promises has its own setTimeout. You call wait(1000) with no callback, and it returns a promise that settles after 1000 ms. as wait gives it a new name in this file. That keeps the ordinary setTimeout, the one the Lesson 3 demo uses, working as before.

sequential awaits three waits one after another:

demos.js 
// GET /demo/sequential: three 1000 ms waits, one after another.
// Each await pauses this function until that wait is done.
export async function sequential(req, res) {
  const start = Date.now();
  await wait(1000);
  await wait(1000);
  await wait(1000);
  res.status(200).json({ waits: 3, eachMs: 1000, elapsedMs: Date.now() - start });
}

parallel starts all three waits on one line. Each wait(1000) starts its timer right away and hands back a promise. Promise.all takes the array of three promises and gives back one promise that settles when all three have settled:

demos.js 
// GET /demo/parallel: the same three waits, all started at once.
// Promise.all waits until every one of them is done.
export async function parallel(req, res) {
  const start = Date.now();
  await Promise.all([wait(1000), wait(1000), wait(1000)]);
  res.status(200).json({ waits: 3, eachMs: 1000, elapsedMs: Date.now() - start });
}

Date.now() is the current time in milliseconds, so Date.now() - start is how long the handler took. In server.js, one line connects each path to its handler:

server.js 
app.get('/demo/sequential', sequential);
app.get('/demo/parallel', parallel);

What just happened

      
Both demos answered HTTP 200 OK with
      "waits": 3 and "eachMs": 1000. Only the time
      was different. Your exact numbers change a little each time you
      click.

      
    
        
  • Sequential: elapsedMs was a little
        over 3000, for example 3015. The second wait did not start
        until the first was done, and the third did not start until the second
        was done: 1000 + 1000 + 1000.
    • 
        
  • Parallel: elapsedMs was a little over
        1000, for example 1008. All three timers counted down at
        the same time, so the whole group was done when the slowest one was
        done.
    • 
      

      
The status line above each answer shows the full trip from your
      browser and back. That is the server's elapsedMs plus the
      time the request spent on the network, so it is a bit larger.

      
If you clicked both buttons, the parallel answer came back first,
      about one second after you clicked it, while the sequential demo was
      still waiting.
      The sequential answer still came back after about three seconds, so
      neither request slowed the other down. That is the event loop at work:
      while sequential was paused at await, the
      server was free to answer the parallel request.

      
The lesson: await pauses one function, not the whole
      server. When the slow steps do not depend on each other, start them
      together with Promise.all.
